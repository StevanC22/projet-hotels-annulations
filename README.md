# Les annulations de deux hôtels portugais

Projet TD2 Machine Learning (M1 CGAO, IGR-IAE Rennes). Contenu : `Projet_COURTES_DIAWARA_LEROUX.ipynb` (analyse, indicateurs, modèle), `app.py` (tableau de bord Streamlit), `reservations_hotels.csv` (données), `MEMOIRE.md` (mémoire du projet pour l'assistant d'IA).

Lancer l'application en local : `pip install -r requirements.txt` puis `streamlit run app.py`.
